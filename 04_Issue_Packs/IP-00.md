# IP-00 — Base reproducible y datos de prueba

**Objetivo:** Crear monorepo frontend/backend, Docker Compose PostGIS, migraciones, fixtures sintéticas, CI y README.

**Dependencias:** ninguna

## Instrucción para agente
Implementar únicamente este alcance. Antes de modificar, inspeccionar repositorio y decisiones del Documento Maestro V0.4. No inventar datos reales ni accesos externos. Entregar código, migraciones, tests, instrucciones de ejecución y evidencia. Si un acceso externo no está autorizado, usar fixture explícita y documentar bloqueo.

## Criterios de aceptación
Se levanta con instrucciones documentadas; tests pasan; datos sintéticos identificados; no claves en repositorio.

## Definition of Done
- Tests automáticos ejecutados y resultados informados.
- Demostración reproducible con pasos.
- Cambios y riesgos documentados.
- Sin dependencias de un agente específico.
- Aprobación humana antes de avanzar.
